Issue #1 · 28 Jun 2026 · Weekly AI Digest

Claude on iPhone,
SpaceX buys Cursor,
ChatGPT loses ground

Big structural shifts this week — distribution, acquisition, and a market share milestone. Plus the open-source tools quietly becoming load-bearing infrastructure.

Big News
ChatGPT dips below 50% market share for the first time
OpenAI's share of the LLM market dropped below the symbolic 50% threshold as Claude, Gemini, and open-source models collectively eat into its lead. This is less about OpenAI struggling and more about the market maturing — multiple strong alternatives now exist across every tier.
IndustryOpenAI
SpaceX acquires Cursor at $60B valuation
The AI coding assistant giant was snapped up by SpaceX, signalling that aerospace and defence are taking AI developer tooling seriously. Cursor has grown to become the de facto AI IDE for many engineers. Implications for Claude's GitHub Copilot competitor positioning are significant.
AcquisitionDev Tools
Claude lands on iPhone via Apple AI Extensions
Anthropic's partnership with Apple means Claude is now accessible natively within iOS via Apple Intelligence Extensions. This dramatically expands Claude's distribution beyond API and Claude.ai — it now lives in the same ecosystem layer as Siri.
AnthropicDistribution
GLM-5.2 beats GPT-5.5 on MIT benchmarks
Tsinghua's GLM-5.2 outperformed GPT-5.5 on MIT's evaluation suite — a notable result for Chinese open research. Benchmark games aside, it continues the trend of multiple frontier-capable models existing simultaneously.

Tools Worth Knowing
Hermes Agent
★ 188K GitHub stars
Nous Research's persistent memory agent framework. Maintains context across sessions — the thing every stateless LLM wrapper wishes it had built in.
Browser-Use
★ 93K GitHub stars
LLM-native browser control. Point an LLM at any website and let it navigate, click, and extract — no Selenium boilerplate required.
Claude Agent SDK
Anthropic · New release
Anthropic's official multi-agent orchestration SDK. Handles tool use, memory, and agent handoffs. The foundation for production-grade Claude agents.
Gemini 3.5 Pro
2M context window
Google's latest with a 2-million token context window. Practically useful for entire codebases or document archives in one prompt.
Wild Card
Microsoft Scout — autonomous research agent for enterprise
Microsoft quietly shipped Scout, an autonomous agent that conducts multi-step research tasks across enterprise data sources. Positioned as "Copilot that actually does the work" — browses, summarises, cross-references, and drafts reports without hand-holding. Early enterprise reception has been strong.

For You — Pin Xiu
Personalised picks

Claude Agent SDK is directly relevant to what you're building. Your Analyst Agent and MapleStory automation are already multi-step Claude workflows — the SDK gives you a proper orchestration layer if you want to formalise them into production agents rather than ad-hoc scripts.

Browser-Use is worth bookmarking for your MapleStory automation extension. You're already using Claude computer use for BlueStacks — Browser-Use could handle the web-facing parts (patch notes, event schedules) without needing full computer use overhead.

Hermes Agent's persistent memory solves the context problem your AI Twin chatbot has between sessions. If you ever want the chatbot to remember a recruiter's name or what they discussed last visit, this is the pattern to study — even if you don't adopt the full framework.

Claude Agent SDK — build multi-agent systems properly
