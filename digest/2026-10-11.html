Issue #14 · 11 Oct 2026 · Weekly AI Digest

Small Models Go Cheap,
Agents Get Inboxes,
Charts Build Themselves

Anthropic prices Haiku 5.5 at ten cents per million tokens, Google gives its Gemini agent its own Gmail and calendar, Claude learns to build live dashboards on Snowflake and Databricks, and two big open-weight models are weeks away from download.

Big News
Claude Haiku 5.5 lands at $0.10 per million input tokens
Anthropic released Haiku 5.5 on 7 October with a 1M-token context window, 128K max output and the first adjustable effort setting on a Haiku. Prompts up to 100K tokens cost $0.10 input / $0.50 output per million (versus $1 / $5 for Haiku 4.5), with longer prompts at $0.50 / $2.50 — matching the price of OpenAI's GPT-6 Luna. Early reviewers caution that Haiku 5.5 can use noticeably more tokens, so measure cost per task, not per token.
ModelsPricing
Google Cloud's Gemini agent gets its own Gmail, calendar and Drive
At Gemini at Work on 8 October, Google Cloud introduced the Gemini agent, a single work agent that answers questions, does knowledge work, creates content and writes code. Each agent gets its own Workspace identity — mailbox, calendar, Drive storage and a directory seat — so colleagues can delegate to it like a teammate, and it only sees what is shared with it. It can run multi-day tasks, reach Slack and Microsoft 365, and use Anthropic's Claude as well as Gemini. It starts in private preview; pricing and a GA date weren't announced.
AgentsEnterprise
Claude Dashboards turns plain-English questions into live charts
Anthropic launched Claude Dashboards and Claude Motion in beta on 8 October. Dashboards connects to Snowflake, Databricks, BigQuery, Redshift, ClickHouse and Salesforce, builds charts that refresh as data changes, and shows the query and last refresh time behind every figure. Motion turns charts, text and images into editable animations exported as MP4. Claude Docs, Slides and Design also came out of beta for all plans. Reuters framed it as the AI labs' push into everyday workplace software.
AnalyticsProductivity
Two trillion-scale open-weight models are on the way: Mistral Large 4 and Reflection Beam
Mistral released Large 4 as a public API preview on 6 October — a roughly 1.05T-parameter multimodal mixture-of-experts model with a 1M-token context window on its model card (independent testers report closer to 512K in practice), with weights promised by the end of October. The same week, Nvidia-backed Reflection unveiled Beam, a 501B-parameter MoE with 23B active parameters, reporting 80.9 on SWE-bench Verified and promising Apache 2.0 weights later this month. Both sets of benchmark figures are self-reported for now.

Tools Worth Knowing
morluto/rea
★ #1 on GitHub Trending, 6–10 Oct
"Reverse Engineer Anything" — an MIT-licensed MCP server and CLI that connects coding agents to Ghidra and IDA Pro so they can work out how a feature in a native binary, Electron app or APK is built. Powerful and dual-use; meant for authorised analysis, and its outputs still need human checks.
alibaba/open-code-review
★ ~22.4k (as of 12 Sep)
Alibaba's Apache-2.0 code reviewer: deterministic pipelines pick files and rules, then an LLM agent leaves line-level comments. Works with OpenAI and Anthropic APIs, GitHub Actions and GitLab CI, and has plugins for Claude Code, Codex and Cursor. Its precision claims are Alibaba's own.
Kore.ai Autoloop
Generally available · 7 Oct
An optimisation engine that keeps tuning agents against business goals — task completion, accuracy, rule adherence, safety and cost — before and after deployment. Its StateTrace feature follows every handoff and tool call. Kore.ai's own survey says 79% of enterprises have had to reverse an action an agent took.
Arena Alignment Index
Preview · Arena raised $200M at $3.1B
Alongside a $200M Series B co-led by Lightspeed and Khosla, the company behind Chatbot Arena previewed an index that scores agents on three failure modes: unauthorised actions, misattributing decisions to users, and claiming a task is done when it isn't.
Wild Card
ChatGPT keeps signing fake New Yorker cartoons with real artists' names
A Nieman Lab investigation found that more than 15 current and former New Yorker cartoonists had their signatures or pen names show up on ChatGPT-generated "New Yorker-style" cartoons — including Brendan Loper's "BLOPER" on a viral Dolly Parton cartoon he never drew. OpenAI called it an unintended bug and added a warning for some requests, but signatures could still appear. Copying a style is one thing; forging the signature that proves who made it is another.

For You — Pin Xiu
Personalised picks

Claude Dashboards on Snowflake. Your Analyst Agent already turns natural-language questions into Snowflake queries, notebooks and slides; Dashboards does the "live chart" part as a product, with the query and refresh time shown under every figure. Watch it closely: showing the SQL behind every number is the same trust pattern your Content Analytics Agent uses with guardrailed SQL, and it's the bar a bank's analytics stakeholders will now expect from any internal agent you ship.

Haiku 5.5 as the cheap router. At $0.10 per million input tokens with a 1M context and an effort dial, Haiku 5.5 is a strong candidate for the high-volume steps in your agents — reading dbt docs, classifying questions, summarising query results — while a bigger model handles the reasoning. Run the same task set through it before switching, though: reviewers say it uses more tokens, so compare cost per finished analysis, the same way you cut Snowflake spend by 60%.

Autoloop and the Arena Alignment Index. As you deploy more agentic products at GXS with Grab, "did the agent say it finished when it didn't?" and "can we trace every tool call?" are exactly the questions risk and compliance will ask. These two launches give you ready-made language and metrics — task completion, unauthorised actions, full execution traces — to build an evaluation scorecard for your agents before they go to production.

Pick of the Week
01
Agents are becoming coworkers with their own accounts
Google giving the Gemini agent its own mailbox, calendar, Drive and directory seat is a design shift: the agent acts under its own identity and only sees what you share, instead of borrowing a human's credentials. That makes permissions, audit trails and offboarding work the way they do for staff, which is what regulated firms need before they let agents run multi-day jobs. Expect other platforms to copy the model, and start planning how your own agents would be given, and limited to, an identity of their own.
